# 演示数据说明

公开演示版只携带一份内置种子：`js/data/seed.js`。

| 项 | 内容 |
| --- | --- |
| 区间 | 2026-09-01 至 2026-09-28（19 个交易日） |
| 标的 | 恒生科技、红利ETF、科创50、港股通创新药 |
| 流水 | 23 笔模拟成交 |
| 存储 | 首次打开写入浏览器 `localStorage`（键名 `position-review-demo:v1.3`） |

种子顶层字段：

- `dates`：可选交易日，升序使用。
- `overview[date]`：总资产、总市值、浮动盈亏、当日盈亏、可用、可取、仓位。
- `holdings[date]`：该日每个标的的快照。数量、成本、现价、市值、当日盈亏、浮动盈亏、`cleared`。
- `trades`：模拟成交。方向有买入、加仓、减仓、卖出、清仓；状态有已成、部成、已撤、未成。卖出可以带 `linked_buy_ids` / `linked_qty_map`。

## 恢复到这份数据

1. 打开页面。
2. 点击 **恢复演示数据**，并在确认框里接受。
3. 日期选回 `2026-09-28`（或任意试验日），总览、持仓、交易都会回到种子内容。

**重置备注**只删除你在本机写下的复盘和持仓备注，不改种子账本。

备注不会写回仓库。要把演示站恢复成刚克隆的样子，使用页面上的「恢复演示数据」即可，不必改 `js/data/seed.js`。
