### 1.1 功能清单（来自 v1.0 PRD 6.3 节）

### 1.2 明确排除（不做，避免范围蔓延）

- **What-If 交易预演（P1-4）** → v1.3（依赖仓位计划 + 行业切片）
- **行业/风格/市场切片（D1/D2）、ETF 重叠检测（D4）、标的主数据（DAQ-4/5）** → v1.3
- **行业/风格维度的集中度告警判定** → 随 v1.3 instruments 数据落地自动生效（详见 1.3 偏差说明 D-v1.2-1）
- **FIFO/LIFO 自动配比开关** → v1.2 仍为用户手选（v1.1.1 已实现），不在本版
- **系统性风险对照、仓位时间线、违规统计** → v2.x
- **永久不做**：实时行情、AI 荐股、社区分享、多用户、一键下单等（同 v1.0 1.4 节）

| 扩展点 | v1.2 体现 | v1.3 接入方式 |

## 二、核心用户故事

### US-1：设定并随时调整我的仓位计划
**作为**我自己，**当**我开始使用 v1.2 时，**我希望**设定 4 项仓位计划参数（目标仓位带、单标的上限、单行业上限、现金下限），
**以便**系统据此判断我每天录入的仓位是否越界；市场状态变化时我可随时调整，调整即时生效。

**验收路径**：看板 → 仓位计划设置入口 → 修改参数 → 保存 → 水位仪表与告警按新阈值立即重算

### US-2：一眼看出当前仓位是否在自己设定的合理区间
**作为**我自己，**当**盘后录入当日持仓后，**我希望**水位仪表直接告诉我"当前仓位 72%，在 60–80% 目标带内"，
**以便**我不需要心算就能确认"我是否处于自己设计好的状态"。

**验收路径**：盘后复盘流 → 录入持仓 → 看板水位卡片 → 环形色带 + 当前值 + 偏离提示

### US-3：仓位或集中度越界时被醒目提醒
**作为**我自己，**当**总仓位越出目标带、单标的占比超限或现金占比低于下限时，**我希望**顶部出现红色告警横幅，
**以便**我在复盘时第一时间看到风险点，可点击跳转到对应持仓卡片核实；已知晓的告警可"今日忽略"，忽略动作留痕到当日复盘。

**验收路径**：看板 → 告警横幅自动展开 → 查看详情跳转 → 今日忽略 → 复盘页可见忽略记录

### US-4：每只持仓的盈亏自动带上体系归因
**作为**我自己，**当**查看持仓卡片时，**我希望**每只持仓的浮动盈亏旁自动标注"体系内-持有/兑现/风控"或"体系外-违规"，
**以便**我能区分"体系该赚的钱"与"违规操作的后果"；判断不同时我可手动改选，系统记录我的覆盖行为。

**验收路径**：看板持仓卡片 → 归因标签 → 下拉改选 → 复盘②段同步显示 → 覆盖留痕

### US-5：一键填入复盘时水位与归因自动就绪
**作为**我自己，**当**盘后写复盘时，**我希望**"一键填入今日快照"后，②段归因已按联动规则填好初值、③段水位是否越界已自动判定，
**以便**我只补充主观判断与明日计划，复盘 10 分钟内完成。

**验收路径**：复盘 Tab → 一键填入 → ②段归因初值 + ③段水位状态 → 补主观内容 → 自动保存

## 三、功能详细需求

### 3.1 P1-1 仓位计划设定（DAQ-3，含三项告警阈值）

#### 3.1.1 功能描述
提供仓位计划设置入口，4 项参数可查看、修改，保存后即时生效（水位/告警立即按新阈值重算）。首次使用写入 v1.0 规定的默认值。

**阈值可设置原则（本版强约束）**：三项告警判定阈值——总仓位水位带（total_position_band）、单标的占比上限（single_position_max）、现金占比下限（cash_min）——**全部为用户可设置参数**。水位仪表与告警横幅完全由用户设置值驱动，代码内置默认值仅用于首次初始化，不构成固定阈值；任一参数修改后，水位仪表、告警横幅、复盘③段立即按新值重算（无需刷新页面）。

#### 3.1.2 参数定义（对应 v1.0 第八章 DB.plan）

| 字段 | 类型 | 默认值 | 取值约束 | 含义 | v1.2 是否参与判定 |
|---|---|---|---|---|---|
| total_position_band | [number, number] | [60, 80] | 0 ≤ 下限 < 上限 ≤ 100，整数 | 目标仓位带（总市值/总资产 %） | 是（DAA-2） |
| single_position_max | number | 25 | 0 < 值 ≤ 100，整数 | 单标的市值占总资产比例上限（%） | 是（DAA-3） |
| single_industry_max | number | 30 | 0 < 值 ≤ 100，整数 | 单行业市值占比上限（%） | **否**（v1.3 生效，v1.2 仅存储） |
| cash_min | number | 15 | 0 ≤ 值 < 100，整数 | 现金占比下限（%） | 是（DAA-3） |

**占比口径（全产品统一定义，v1.3 沿用）**：

```
仓位%（position_pct） = 总市值 / 总资产 × 100%
单标的占比            = 该标的市值 / 总资产 × 100%      ← 分母为总资产（含现金），账户整体视角
现金占比              = (总资产 − 总市值) / 总资产 × 100%
```

#### 3.1.3 交互流程

```
[入口] 看板水位卡片右上角"计划设置"按钮 + 顶部工具区设置图标
   ▼
仓位计划与告警阈值设置弹窗（4 项参数表单，显示当前值与默认值提示）
   ├─ 实时校验：数值范围 / 仓位带下限 < 上限
   ├─ 非法输入 → 保存按钮禁用 + 红字提示
   └─ 单行业上限旁标注灰色小字「v1.3 行业数据落地后生效」
   ▼
[保存] → 写入 DB.plan（含 updated_at）
   ▼
即时生效：DAA-2/DAA-3 全量重算 → 水位仪表刷新 → 告警横幅刷新
   （若当日已有点击过"今日忽略"的告警，参数变更后该忽略记录作废，重新展示告警）
```

#### 3.1.4 边界条件
- **首次启动无 plan**：以默认值初始化并落库，用户未设置前即按默认值判定（默认值即 v1.0 推荐值）。
- **计划与当前仓位冲突**：保存时不阻断（计划是目标而非限制），但保存后立即展示对应告警。
- **总资产未录入当日快照**：水位/告警显示"—"与"请先录入当日持仓"提示，不判定。

#### 3.1.5 v1.3 扩展点
- What-If 读取 plan 作为模拟交易的触阈判定基准。
- 行业维度告警直接启用已存储的 single_industry_max。

### 3.2 P1-2 仓位水位仪表（DAA-2）

#### 3.2.1 功能描述
将看板总览区第 4 卡片「仓位%」（v1.1.2 的 `#waterfallSlot`）升级为水位仪表卡片：环形图 3 段色带 + 当前仓位值 + 与目标带的偏离差值，可下钻查看占比明细。

#### 3.2.2 展示规格

```
┌─────────────────────────────┐
│ 仓位水位          [计划设置] │
│  ┌───────────┐   72.0%     │
│  │  (环形图)  │   在带内 ✓   │
│  │  黄|绿|红  │   目标 60–80%│
│  └───────────┘             │
│ 偏离：带内（距上限 8.0pp）    │
│ [查看占比明细 ▾]            │
└─────────────────────────────┘
```

| 元素 | 规则 |
|---|---|
| 环形色带 | 0–下限：黄色带；下限–上限：绿色带；上限–100：红色带（色带弧长按 plan 动态绘制） |
| 指针/当前值 | 当前 position_pct 以指针或高亮弧段标示，中心或右侧大字显示数值（1 位小数） |
| 状态判定 | 在带内（绿）/ 高于上限（红）/ 低于下限（黄） |
| 偏离差值 | 带内：显示"距上限 X.Xpp / 距下限 X.Xpp"；越界：显示"超出上限 +X.Xpp"或"低于下限 −X.Xpp" |
| 下钻 | 展开占比明细列表：各标的市值占比降序 + 现金占比，超阈行红色高亮（与 P1-3 告警联动） |
| 数据缺失 | 总资产或总市值缺失时显示「—」，不绘制色带判定 |

#### 3.2.3 写入复盘
- 每次当日快照（holdings/overview）保存或 plan 变更后，系统计算当日水位状态并写入 `DB.reviews[date].position_in_band`（true/false/null）与 `water_level` 明细（见第四章数据模型）。
- 复盘 Tab ③段展示该状态（只读，由系统填充），不再为占位字段。

#### 3.2.4 边界条件
- position_pct 恰等于边界值（60.0 或 80.0）→ 判定为**在带内**（闭区间）。
- 历史日期切换看板时，水位仪表按**该日期的快照**与**当前 plan** 判定（plan 不保留历史版本，v1.2 不做计划变更历史）。
- 偏离差值统一保留 1 位小数，单位为"pp"（百分点）。

#### 3.2.5 v1.3 扩展点
- What-If 抽屉复用同一水位渲染组件展示"交易后水位"。
- 占比明细列表扩展行业/风格列（D1/D2）。

### 3.3 P1-3 集中度告警（DAA-3）

#### 3.3.1 功能描述
顶部告警横幅：任一维度超阈时自动展开，支持查看详情跳转与"今日忽略"，忽略记录写入当日复盘。

#### 3.3.2 判定维度（v1.2 三项，DAA-3 可插拔）

| 维度 | 判定规则 | 告警文案示例 |
|---|---|---|
| 总仓位水位 | position_pct > band 上限 → 超上限；< band 下限 → 低于下限 | "总仓位 85.0%，超出目标带上限 80%（+5.0pp）" |
| 单标的占比 | 任一未清仓标的 市值/总资产 > single_position_max | "科创50 占比 27.3%，超过单标的上限 25%" |
| 现金占比 | cash_pct < cash_min | "现金占比 12.0%，低于下限 15%" |

- 判定时机：当日快照保存后、plan 变更后、切换看板日期后，全量重算。
- 同一维度多个标的超阈时，告警逐项列出（单标的维度可能多条）。

#### 3.3.3 横幅交互

```
┌──────────────────────────────────────────────────────────┐
│ ⚠ 3 项仓位告警                              [收起 ▴]     │
│ ├─ 总仓位 85.0% 超出上限 80%（+5.0pp）     [查看] [今日忽略]│
│ ├─ 科创50 占比 27.3% 超过上限 25%         [查看] [今日忽略]│
│ └─ 现金占比 12.0% 低于下限 15%            [查看] [今日忽略]│
└──────────────────────────────────────────────────────────┘
```

| 交互 | 规则 |
|---|---|
| 自动展开 | 存在超阈项时自动展开；无超阈时不渲染横幅 |
| 查看详情 | 跳转到对应位置：单标的告警 → 滚动至该持仓卡片并短暂高亮；水位/现金告警 → 展开水位卡片占比明细 |
| 今日忽略 | 单项忽略：该告警当日不再展示（含收起后），并写入 `DB.reviews[date].ignored_alerts`（留痕：维度/标的/阈值/实际值/忽略时间） |
| 忽略失效 | ① 跨自然日自动失效；② plan 参数变更后全部失效重新判定 |
| 不打断操作 | 横幅为页面顶部常驻区域，不弹窗、不阻断任何录入流程 |

#### 3.3.4 边界条件
- 当日无快照：不判定、不展示横幅。
- 忽略后当日该维度数值进一步恶化：v1.2 不重新弹出（保持"今日忽略"语义），复盘记录中保留忽略时的数值快照供对照。
- 已清仓标的不参与单标的占比判定。

#### 3.3.5 v1.3 扩展点
- 新增行业/风格维度告警项，复用同一横幅与忽略机制。
- What-If 预演触发的告警项在抽屉内以相同样式预览（不落 ignored_alerts）。

### 3.4 S2 盈亏归因到体系（DAA-4）

#### 3.4.1 功能描述
每只持仓（含当日已清仓）的浮动盈亏旁展示归因标签与下拉；默认标签由联动规则自动计算；用户可手动覆盖（违规除外），覆盖行为留痕。复盘②段与看板标签共享同一份数据。

#### 3.4.2 归因标签体系

| 标签 | 分类 | 含义 | 默认联动规则 |
|---|---|---|---|
| 体系内-持有 | 体系内 | 理由未变，正常持有中的浮动盈亏 | 存在该标的未平仓买入记录，且当日无该标的卖出 |
| 体系内-兑现 | 体系内 | 理由兑现卖出（该赚的钱） | 当日该标的存在 sell_type=兑现 的卖出 |
| 体系内-风控 | 体系内 | 证伪/失效卖出（体系内正常风控成本） | 当日该标的存在 sell_type=证伪 或 失效 的卖出 |
| 体系外-违规 | 体系外 | 无对应买入理由的违规卖出 | 当日该标的存在 sell_type=违规 的卖出（**强制**） |
| 待归因 | — | 无买入理由记录，需人工判断 | 该标的无任何未平仓买入记录且当日无卖出 |
| 体系外-判断失误 | 体系外 | 用户主观认定的体系外操作 | 仅由用户手动改选产生，系统不自动判定 |

**同日多卖出类型优先级**（当日同一标的有多笔不同类型卖出时取最高优先级）：
`体系外-违规 > 体系内-风控 > 体系内-兑现 > 体系内-持有`

#### 3.4.3 联动与覆盖规则

```
默认标签计算（DAA-4）：
  for 当日 holdings 每个标的（含当日已清仓）：
    违规卖出存在? → 体系外-违规（锁定）
    else 证伪/失效卖出存在? → 体系内-风控
    else 兑现卖出存在? → 体系内-兑现
    else 存在未平仓买入记录? → 体系内-持有
    else → 待归因

用户覆盖：
  - 违规（体系外-违规）：下拉锁定，仅可在「体系外-违规 / 体系外-判断失误」间切换，
    不可改为任何体系内标签（验收铁律）
  - 其他标签：下拉可在全部 6 个标签间改选
  - 每次覆盖写入留痕：{name, from, to, at} 追加至 DB.reviews[date].attribution_overrides
```

#### 3.4.4 数据一致性
- 归因数据唯一存储于 `DB.reviews[date].pnl_attribution = {name: 标签}`；看板持仓卡片与复盘②段读取同一数据源，任一处修改即时同步另一处。
- 看板卡片展示的是"当前生效标签"：有覆盖用覆盖值，否则用 DAA-4 默认值（默认值不提前落库，用户覆盖或保存复盘时才写入）。
- "一键填入今日快照"时：②段归因段以 DAA-4 默认值为初值（已覆盖/已手填的不被重置）。

#### 3.4.5 边界条件
- 当日无持仓快照：复盘②段显示"请先录入当日持仓"（沿用 v1.1.2）。
- 待归因标签的持仓：复盘保存时不强制处理，但②段显示黄色"待归因"提示，引导用户选择。
- 历史日期查看：展示当日实际保存的归因值（含覆盖），不按当前 trades 重算（留痕优先）。

#### 3.4.6 v1.3 / v2.x 扩展点
- v2.x 违规统计基于 `attribution_overrides` + sell_type 聚合。
- v3.x 理由命中率按 reason_type × 归因标签交叉统计。

### 5.3 关键交互铁律

1. **归因数据单源**：看板与复盘读写同一 `pnl_attribution`，禁止出现两处不一致。
2. **违规不可洗白**：sell_type=违规 的标的，归因下拉不出现体系内选项。
3. **告警不打断**：横幅不弹窗、不阻断录入；忽略必须留痕。
4. **计划即时生效**：plan 保存后无需刷新页面，水位/告警/复盘③段立即重算。
5. **录入即重算**：当日快照保存后自动重算水位/告警/归因默认值。
6. **历史留痕优先**：查看历史日期时展示当日保存值，不按当前数据重算归因与忽略记录。

## 六、异常处理与边界条件汇总

| 场景 | 处理 |
|---|---|
| plan 参数非法（下限≥上限、超范围） | 保存按钮禁用 + 红字提示 |
| 首次启动无 plan | 默认值 [60,80]/25/30/15 自动初始化落库 |
| 当日无 overview 或 total_assets 为空 | 水位/告警显示「—」+「请先录入当日持仓」，不判定 |
| 总资产 ≤ 0 | 同上，不判定（防除零） |
| 当日无持仓但有 overview | 仓位 0%、现金 100%，正常判定（可能触发"低于下限"告警，属预期） |
| position_pct 恰等于边界 | 判定为在带内（闭区间） |
| 已清仓标的 | 不参与单标的占比判定；参与当日归因（卖出联动） |
| 无买入理由记录的持仓 | 归因默认「待归因」，复盘黄色提示 |
| v1.1 自由文本归因旧数据 | 原样展示，视为自定义覆盖，不强制迁移 |
| plan 变更后存在当日忽略记录 | 忽略记录作废，告警重新展示（ignored_alerts 保留历史仅作复盘留痕） |
| localStorage 写入失败 | 沿用 v1.1.2 StorageFullException 提示链路 |
