# 持仓复盘工具（Position Review）

> **公开演示：** 这是公开 demo。内置数据（`js/data/seed.js`）全部是虚构演示数据，不是真实持仓或账户。

> 一款面向个人投资者的**纯前端**持仓与交易复盘工具。
> 核心理念：**「买入必须写明理由，卖出必须对照理由」** —— 把交易体系变成可被追踪、可被校验、可被追责的执行闭环。

当前版本：**v1.3.1（分散度与 What-If 版）** ｜ Schema：v1.3 ｜ 类型：纯前端单页应用（无后端、无构建步骤）

## 1. 项目概述

本工具服务于单一用户（作者本人）的盘后复盘场景：持仓 5–15 只标的，每日收盘后花 10–20 分钟完成复盘。工具围绕三大核心痛点设计：

| 痛点 | 对应模块 |
|---|---|
| 买入理由 ≠ 卖出理由，没有贯彻"同一理由" | **理由闭环追踪**：买入理由结构化记录、卖出强制对照、买卖配对对账、违规清单 |
| 仓位管理缺乏整体性 | **整体仓位管理**：仓位计划、水位仪表、大盘温度中枢、集中度告警 |
| 仓位分散度理解不足 | **分散度透视**：行业/风格/市场切片、ETF 重叠检测、What-If 预演 |

工具的三大可验证目标：

1. **买卖理由闭环**：每笔卖出都能追溯到买入理由（兑现 / 证伪 / 失效 / 违规）。
2. **盈亏归因到体系**：识别"体系外的违规操作"并单独标记。
3. **整体仓位抗系统性风险**：组合温度驱动仓位中枢，分散度透视识别集中度风险。

明确**不做**的范围：实时行情、AI 荐股、社区分享、多用户账号、回测/蒙特卡洛/因子分析、税务多币种、一键下单。

## 2. 功能特点

### 已实现（v1.3.1）

#### 理由闭环（v1.1 起）
- **持仓看板**：总资产 / 总市值（含仓位占比）/ 浮动盈亏 / 仓位 4 项核心指标；持仓市值分布饼图、浮动盈亏排行柱状图（Chart.js）；持仓明细卡片，支持显示/隐藏已清仓标的。
- **交易流水**：5 种交易方向（买入/加仓/卖出/减仓/清仓）；按标的、理由、说明关键词即时搜索（防抖）。
- **R1 结构化买入理由**：核心理由、理由类型（基本面/技术面/事件/估值/情绪）、预期持有周期、失效条件、目标区间、止损位等字段必填，保存按钮层强制校验 + 软警告双机制。
- **R2 卖出强制对照**：卖出必须选择「兑现 / 证伪 / 失效 / 违规」四分类之一；非违规卖出必须关联买入记录且消耗数量精确勾稽；违规卖出不消耗买入、永久进入违规清单。
- **理由对账视图**：按标的分组展示买卖配对、未平仓量、闭环状态（OPEN / PARTIAL / CLOSED），支持日期区间与状态筛选；顶部汇总违规清单。
- **四段式每日复盘**：今日操作 / 盈亏归因 / 仓位水位 / 明日计划；输入即自动保存（防抖），可一键填入当日快照。

#### 数据录入
- **手动录入持仓**：表格化录入当日持仓（标的/持仓量/成本/现价 4 列最小输入集），浮动盈亏等衍生指标自动计算，保存即生成当日快照。
- **截图 OCR 预填**：上传券商持仓截图（JPG/PNG/WEBP ≤5MB），浏览器本地 Tesseract.js 识别，置信度颜色标记，**逐项确认后才落库**——OCR 结果永远只是预填。
- **数据管理**：按日期/按标的精确删除（先展示影响范围，买卖关联约束保护）；一键重置全部（勾选确认 + 4 秒二次点击双保险，可选恢复演示数据）；全量 JSON 导出备份。
- **自动迁移**：旧版本数据首次启动自动合并进当前结构，仅执行一次，不覆盖同日已有数据。

#### 仓位与温度（v1.2 起）
- **仓位计划**：设定总仓位目标与单标的上限，超限自动告警。
- **仓位水位仪表**：实时仓位占比可视化，对照计划中枢直观显示偏离。
- **大盘温度与仓位中枢**：
  - 总温度 = 50% 指数位置 + 50% 量能（线性插值，0–100 封顶）
  - 指数位置：上证收盘相对 40 周均线偏离（锚点 -15%→0, 0%→50, +15%→100）
  - 量能：5 日均成交额 ÷ 250 日均成交额（锚点 0.5→0, 1.0→50, 1.5→100）
  - 仓位中枢 = 100 − 温度，每日收盘后计算、次日生效
  - 温度 >80（过热区）：仅卖出，不发新信号；<20（冰冻区）：允许 90%+ 仓位并提示风险
- **集中度告警**：单标的仓位超限时顶部横幅提醒。
- **盈亏归因**：归因与当日快照联动自动填充。
- **深色主题**：Tailwind 调色板反转重映射，夜间复盘护眼。

#### 分散度与 What-If（v1.3 新增）
- **组合切片**：按行业、风格、市场对持仓进行切片统计，识别组合暴露。
- **ETF 重叠检测**：分析持仓 ETF 之间的成分股重叠度，避免"看似分散实则集中"。
- **What-If 交易预演**：在不修改真实数据的前提下，模拟买入/卖出对仓位、集中度、浮动盈亏的影响。
- **标的信息管理**：维护标的基础信息（名称、类型、市场、行业等），支撑切片与重叠分析。

## 3. 技术栈

| 层 | 技术 |
|---|---|
| 语言 | 原生 HTML / CSS / JavaScript（ES5+，IIFE 模块模式） |
| UI 框架 | Tailwind CSS（CDN） |

## 4. 安装与运行

无需安装任何依赖，纯静态页面。

```bash
# 克隆仓库
git clone https://github.com/Steph36644/position-review-v1.1.2.git
cd position-review-v1.1.2

# 方式一：直接用浏览器打开 index.html

# 方式二（推荐）：启动静态服务器
python -m http.server 8080
# 或
npx serve .
```

然后浏览器访问 `http://localhost:8080`。

**环境要求**：
- 现代浏览器（Chrome / Edge 推荐），需支持 IndexedDB。
- 首次打开需联网加载 CDN 资源（Tailwind、Chart.js、Tesseract.js、字体）；断网时业务录入仍可用，但样式/图表/OCR 受影响。
- 全部业务数据保存在**当前浏览器本地**，不上传服务器。

运行逻辑测试：

```bash
cd test
node logic_test.js
```

## 5. 使用说明

### 首次打开

自动写入一份内置演示数据（含「恒生科技 / 红利ETF / 科创50 / 港股通创新药」等标的），方便直接体验各功能。

### 日常复盘流程

1. **录入当日持仓**：点击「手动录入持仓」或「上传截图(OCR)」，只填 标的/持仓量/成本/现价，保存生成当日快照。
2. **记交易**：点击「记一笔交易」选择方向——买入/加仓需完整填写 R1 理由；卖出需选择四分类并关联消耗的买入记录。
3. **看板复盘**：切换日期查看历史快照，关注总资产、仓位占比、浮动盈亏排行。
4. **理由对账**：定期检查对账页的闭环状态与顶部违规清单。
5. **写每日复盘**：在复盘 Tab 按四段模板填写，自动保存。
6. **仓位与温度**：查看大盘温度与仓位中枢，对照当前水位决定加减仓。
7. **分散度透视**：用组合切片与 ETF 重叠检测检查组合集中度。

### 关键规则速查

- **卖出四分类**：兑现（到达目标区间）/ 证伪（逻辑被证错）/ 失效（触发失效条件）/ 违规（计划外卖出）。
- **消耗勾稽**：非违规卖出勾选的各买入消耗数量之和必须**恰好等于**本次卖出数量，且不超过各买入的未平仓量。
- **违规卖出**：不能关联买入、说明至少 5 字、永久进入违规清单。
- **仓位中枢**：= 100 − 大盘温度，每日收盘后计算、次日生效。
- **重置全部**：需勾选确认框，且 4 秒内二次点击才执行；执行前请先「导出备份」。

## 8. 对账与闭环判定规则

对账引擎按标的分组，对每条有效买入（已成交/部分成交）计算：

- **已消耗数量** = 关联到该买入的非违规卖出消耗数量之和
- **未平仓量** = 买入数量 − 已消耗数量（≥ 0）
- **闭环状态**：`OPEN`（未消耗）/ `PARTIAL`（部分消耗）/ `CLOSED`（消耗 ≥ 买入量）
- **违规标记**：关联卖出中存在「违规」分类即标记；违规卖出不消耗买入，独立进入违规清单
