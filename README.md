# 持仓复盘 Demo

这是**公开演示版**，用浏览器直接打开的静态页面。仓库里只有一套虚构试验数据，用来演示持仓快照、账户总览和交易流水怎么放在一起看。

试验区间是 **2026-09-01 至 2026-09-28**：4 个虚构标的（恒生科技、红利ETF、科创50、港股通创新药），23 笔模拟成交。数字、席位和复盘理由都是编出来的，不对应任何真实账户，也不能当成投资建议。

页面不连接服务器。账本和你自己写的备注都留在当前浏览器的 `localStorage` 里。

## 本地打开

在仓库根目录起一个静态文件服务，然后打开 `index.html`：

```bash
python3 -m http.server 8080
```

用浏览器访问 `http://127.0.0.1:8080/`。直接双击 `index.html` 时，个别浏览器会拦截本地脚本，用上面的方式更稳妥。

GitHub Pages 可以把分支 `main` 的根目录当作站点发布，不需要构建。

## 重置和恢复演示数据

页面右上角有两个按钮，都只影响当前浏览器：

- **重置备注**：清掉复盘文字和持仓卡片上的当日备注，试验账本保持不动。
- **恢复演示数据**：用仓库里的 `js/data/seed.js` 重新写入账本，并清空备注。本地如果改过 `localStorage`，用这一下可以回到内置的虚构试验数据。

第一次打开页面时，如果这台浏览器还没有演示账本，会自动写入同一份种子。

## 数据怎么读

- **总览 / 持仓**来自每日试验快照（`holdings` 与 `overview`）。
- **交易**是同一区间的模拟流水。已撤、未成不计入「按流水推算的剩余数量」；部成按种子里的成交数量计算。
- 快照数量和流水推算数量是两套并列的演示数字，流水不会回写快照。

种子字段对应 Schema 1.3 的演示形状：`trades`、`dates`、`holdings`、`overview`。说明见 [docs/demo-data.md](docs/demo-data.md)。
