    温度评分公式（每日收盘后计算，次日生效）

    总温度 = 指数位置 × 50% + 量能 × 50%

    两维度均按锚点间线性插值打分，0 封底、100 封顶；数据不足的维度自动跳过并归一化

    指数位置（对 40 周线乖离率）

    乖离 ≤ −15% → 0

    乖离 0%（=40周线） → 50

    乖离 ≥ +15% → 100

    量能（5日 / 250日均成交额，沪深合计）

    量比 ≤ 0.5 → 0

    量比 1.0（=年均量） → 50

    量比 ≥ 1.5 → 100

    核心公式

    仓位中枢 = 100 − 温度

    温度 0 → 满仓 100%；温度 100 → 空仓 0%
